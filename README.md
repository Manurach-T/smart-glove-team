# ถุงมืออัจฉริยะแปลภาษามือ — งานของทีม

ถุงมือที่ผู้ใช้สอนท่าใหม่ได้เอง: ทำท่าซ้ำ 5 ครั้ง + พิมพ์ความหมาย → ถุงมือจำได้ทันที
ความหมายของแต่ละท่าผู้ใช้กำหนดเอง (ไม่ใช่ภาษามือไทยทางการ และไม่ใช่เครื่องมือแพทย์)

## ในนี้มีอะไร

| โฟลเดอร์ | ของใคร | แก้ได้ไหม |
|---|---|---|
| `starter/` | ไฟล์เริ่มต้นที่ครูให้ทุกคาบ | **ห้ามแก้** คัดลอกไปไว้ในโฟลเดอร์ตัวเองก่อนแล้วค่อยแก้ |
| `<ชื่อเล่น>/` | ของแต่ละคน | แก้ได้เฉพาะโฟลเดอร์ของตัวเอง |
| `<ชื่อเล่น>/logs/` | บันทึกการเรียนรู้ | เขียนทุกคาบ ไฟล์ละคาบ เช่น `s04.md` |

## กติกาส่งงาน (ทุกคาบ)

1. คัดลอกไฟล์จาก `starter/<คาบ>/` ไปไว้ใน `<ชื่อเล่น>/<คาบ>/` แล้วทำงานในนั้น
2. เขียนบันทึกการเรียนรู้ `<ชื่อเล่น>/logs/<คาบ>.md` ตามแม่แบบ `starter/learning-log-template.md`
3. GitHub Desktop: ติ๊กเฉพาะไฟล์ของตัวเอง → เขียน Summary บอกว่าทำอะไร → **Commit** → **Push origin**
4. Push ไม่ผ่าน (มีงานเพื่อนใหม่กว่า) ให้กด **Fetch origin** → **Pull origin** ก่อน แล้ว Push ใหม่
